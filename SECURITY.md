# Security policy

This is a research prototype, not a biometric identity, surveillance, checkout or anti-theft product. Report vulnerabilities privately to the repository owner, ideally via GitHub's private vulnerability reporting if enabled. Never paste identities, camera recordings, consent forms, secrets, or credential values in public issues. If a credential is exposed, rotate it immediately; merely deleting a file does not revoke it.

Raw recording storage and public visualization remain blocked until M7 security/privacy checks.
