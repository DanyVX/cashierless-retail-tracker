# M5 event/cart state machine
Tracks are ephemeral and per-session. A PICK requires the shelf count to decrease after a qualifying hand dwell; RETURN increases it. Ambiguous wrist-to-track matches are unattributed, low confidence creates a review event, duplicates within a configurable interval are suppressed, out-of-order updates fail closed, and returns never drive counts below zero. Cart transfers on ID switches are **not** done silently. `end_session(track_id, time)` is available to callers after an exit-line or track-lost signal but exit-line integration remains planned; real checkout/payment is excluded. The integration backend uses synthetic colored rectangles and magenta wrist markers, **not actual shopper pose or product recognition**.
